## 实际 Obsidian 验收

桌面 Obsidian 1.14.4，隔离的 `新功能测试仓库`。运行脚本：`node scripts/verify-obsidian.mjs`。脚本只新建唯一命名的脱敏测试笔记，不覆盖既有文件，不写验收者的剪贴板。

以下七组行为已实际通过：

1. 编辑器右侧按钮绑定所属代码块，与光标位置无关；超大整数保持，单次撤销完整恢复。
2. 当前文档预览应用成功，时间戳、IP、日志前缀及其他语言块保持；批量修改可单次撤销。
3. JS 对象字面量预览成功，源笔记保持不变。
4. 字符串化响应字段转对象成功，普通路径字符串保持；撤销恢复字段类型。
5. 预览期间修改笔记后，应用被拒绝，最新编辑和未格式化日志都保持。
6. 按钮设置即时隐藏和恢复；五项设置定义可供新版宿主搜索。
7. 阅读模式按钮按源章节及内容定位，切换到源编辑器完成可撤销修改。

宿主 dev:errors 未捕获产品错误。实时预览按钮与原生语言标签采用同一行浮动排布：原生标注居右，格式化按钮紧邻其左侧，间距 8px，不再依赖固定宽度避让。实际两个 JSON 块的 DOM 边界检查均为 `overlap: false`，按钮与标注顶边对齐。该样式只作用于带 Loose JSON 按钮的围栏行。

桌面移动模式模拟中，插件重新加载后可显示按钮，触屏按钮最小高度为 36px；验证后已恢复桌面模式。此项不等同于原生移动端验证。

脚本复跑时需保持测试库窗口可见，隐藏窗口中的阅读视图不会渲染。脚本将此情形记录为 `skipped`、`complete: false`，不把已跳过的阅读检查当作成功；上述阅读验收来自窗口可见时的实际操作。最终构建的隐藏窗口复跑完成前六组检查。
