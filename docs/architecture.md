# 实现边界

本项目独立实现，不复用原插件源码。产品提供块/选区排版、文档日志排版、JS 字面量复制、字符串化 JSON 字段转换、严格 JSON 修复及日志拆块能力。

## 核心处理

- `syntax.ts` 保留每个 token 原文和偏移。排版前后核对 token 序列，只调整布局空白；转换树保留重复 key、顺序和数值文本。
- `engine.ts` 在引号/注释状态下匹配结构。截断结构仅在明确时间戳日志记录处恢复。普通日志只处理可解析对象/数组；显式 json/无语言块或选区可预览不完整结构，保留未闭合字符串和注释尾部。
- `candidates.ts` 独立检测完整值、属性片段和日志最外层候选；已排版的对象仍能提取，明确赋值的 null 也能识别。两位和四位日志日期共用边界定义。
- `conversion.ts` 生成 JS 上下文形态和严格 JSON。修复只允许确定的结构闭合，数值源文本或 BigInt 十六进制转换避免 Number 精度丢失；JSON.parse 只作最终校验，不用于重序列化。缺值、缺字符串、NaN/Infinity 均拒绝修复。
- `markdown.ts` 定位围栏并保护 YAML、行内代码、链接与其他语言块。引用/列表块内容剥离前缀后处理，应用时恢复容器。
- 字段转换只修改所选字符串节点，不递归处理新对象的字符串。源位置区分重复 Pointer。内部 JSON 默认严格校验，最多三层解码。

## 排版引擎选择

方案允许在 js-beautify 无法满足原 token 保持时使用独立排版器。最终使用独立 token 排版器，直接保证数组布局和数据文本保持，避免通用 JavaScript 美化器修改日志标点。JSON5 仅负责字符串及属性名解码，不用于整个对象的数值序列化。

## 宿主集成

命令通过公开 Editor API，按钮通过 CodeMirror 6 扩展；CodeMirror 和 Obsidian 从宿主加载，不打包重复实例。工作线程代码随主插件打包，以本地 Blob 启动，可取消并在卸载时终止。

阅读模式附加原生代码块按钮，按源章节与内容匹配真实代码块。唯一匹配后打开对应源笔记并使用编辑器事务；不通过 DOM 原文直接回写文件。这比在阅读模式直接写 Vault 保留更可靠的撤销能力。位置有歧义则提示在编辑模式操作。

所有预览应用均要求完整快照未改变；批量修改一个事务完成。预览每批加载 50 项，允许全选、全不选和取消单项。所有内容均按文本展示。修复可插入副本或显式替换。日志提取通过候选源范围在原位置包围数据，保留外围文字、记录顺序及未选中候选；整个日志围栏拆开时移除外层围栏。完整结果预览、复制和应用共用范围拼接逻辑；单次编辑器事务保持撤销。

`i18n.ts` 集中中英文文案，getLanguage 读取公开宿主语言。核心错误和警告采用稳定 code/params/cause 协议跨线程传递；日志变量与数据不翻译。全文、字段转换和 JS 复制预览可独立关闭，修复/提取保持审查。处理诊断仅保存在内存，不将接口内容写入配置。

## 已知支持边界

- JSON5 常见数据语法可用，不支持任意 JS 表达式或执行代码。
- 自动扫描不能保证推断所有损坏日志；不确定的结构跳过。
- 最低版本声明为 1.8.7，已通过官方静态 API 检查；实际运行验收使用桌面 Obsidian 1.14.4。
- 移动端不使用 Node API，但发布前仍需真机验证。
- 大整数原文保持不等于 JS Number 求值无精度风险，复制窗口会提示。
